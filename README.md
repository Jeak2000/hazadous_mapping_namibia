# Hazardous Mapping Namibia

## Project description

This repository contains the data, scripts, analysis and
results from our MSc project on hazardous settlement expansion
and extreme rainfall in urban informal settlements in Namibia.

## Research focus

The project investigates the expansion of informal settlements
into areas vulnerable to flooding and other hazards associated
with extreme rainfall.

## Study areas

- Windhoek
- Oshakati
